Source Code Execution
① Initialisation
Weights start at zero before any training. w = 0 ,   b = 0
② Linear Combination — Step 4
Computes the raw score for each sample. zᵢ = w · xᵢ + b    for i = 1…n
③ Sigmoid Function — Step 5
Maps z ∈ (−∞, +∞) to probability ∈ (0,1). σ(0)=0.5 · σ(+5)≈0.993 · σ(−5)≈0.007 ŷᵢ = σ(zᵢ) = 1 / (1 + e−zᵢ)
④ Binary Cross-Entropy Loss — Step 6
Penalises confident wrong predictions. L → 0 when ŷ matches y perfectly. L(w,b) = −(1/n) Σ [ yᵢ log(ŷᵢ) + (1−yᵢ) log(1−ŷᵢ) ]
⑤ Gradients — Step 7
Direction of steepest increase in loss. We move against the gradient. ∂L/∂w = (1/n) Σ (ŷᵢ − yᵢ) · xᵢ ∂L/∂b = (1/n) Σ (ŷᵢ − yᵢ)
⑥ Parameter Update — Step 8
α = learning rate. Small α → slow but stable. Large α → fast but may overshoot. w ← w − α · ∂L/∂w b ← b − α · ∂L/∂b
⑦ Decision Boundary — Step 9
The vertical threshold crossing on the sigmoid curve. σ(wx+b) = 0.5 ⟹ wx+b = 0 ⟹ x* = −b/w
⑧ Prediction
ŷ = 1 if σ(wx+b) ≥ τ else 0    (τ = threshold)
