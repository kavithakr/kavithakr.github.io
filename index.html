Regression
Supervised learning — predict a continuous output value and explore the effect of regularization on model complexity
3 algorithms
📈
Linear Regression
OLS
Fits a straight line to continuous data by minimising Mean Squared Error using gradient descent. Watch the regression line shift with every weight and bias update as the loss decreases.
MSE Loss Gradient Descent Weight & Bias Regression Line
⟶ 1 step per snapshot Open
🔷
Ridge Regression
L2
Adds an L2 penalty term (λ Σw²) to the MSE loss to shrink weights toward zero and prevent overfitting. The canvas shows how the regression line and loss both change as λ increases.
L2 Penalty Regularization λ (Lambda) Weight Shrinkage
⟶ MSE + penalty visible per step Open
💎
Lasso Regression
L1
Adds an L1 penalty term (λ Σ|w|) that can drive feature weights to exactly zero, effectively performing automatic feature selection. Watch weights collapse to zero as λ grows.
L1 Penalty Feature Selection λ (Lambda) Sparse Weights
⟶ Weight sparsity visible per step Open

Classification
Supervised learning — predict a discrete class label from labelled training data
3 algorithms
📈
Logistic Regression
LR
Learns a decision boundary by fitting a sigmoid curve to labelled data using gradient descent. Watch weights and bias update after every iteration as the loss decreases.
Sigmoid Gradient Descent Binary Cross-Entropy Decision Boundary
⟶ ~50 execution steps Open
🌳
Decision Tree
DT
Builds a tree by recursively selecting the feature with the highest information gain. The tree grows node by node as you step through the algorithm. Supports any dataset.
Entropy Information Gain Gini Index Recursive Split
⟶ Dynamic — grows with data Open
📍
K-Nearest Neighbours
KNN
Classifies a query point by finding the k closest training points and taking a majority vote. Each distance is computed and shown step by step with a labelled line on the scatter plot.
Euclidean Distance Manhattan Distance Majority Vote Click-to-Query
⟶ 1 step per training point Open
🔵
Clustering
Unsupervised learning — discover natural groupings in unlabelled data
2 algorithms
⚙️
K-Means Clustering
K-Means
Iteratively assigns each point to its nearest centroid and recomputes centroids until convergence. Points are coloured one by one as their distance is computed. Supports manual centroid placement by clicking the plot.
Centroids WCSS Convergence Click-to-Place
⟶ 1 step per point per iteration Open
🌿
Agglomerative Clustering
HAC
Bottom-up hierarchical clustering — starts with each point as its own cluster and merges the closest pair at each step. Watch the dendrogram build merge by merge and the distance matrix update after each linkage.
Single Linkage Complete Linkage Average Linkage Dendrogram
⟶ 3 steps per merge Open
